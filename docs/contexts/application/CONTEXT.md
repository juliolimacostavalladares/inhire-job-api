# Application — linguagem do domínio

- **Application Intent:** pedido explícito ou automático para candidatar um Candidate a um Job.
- **Application:** agregado que acompanha a intenção até um estado terminal.
- **Resume Mode:** escolha entre currículo existente e currículo sob medida.
- **Application Package:** snapshot validado de vaga, candidato, respostas e artifact.
- **Application Orchestrator:** regra que coordena preparação, currículo e submissão.
- **Attempt:** execução numerada de uma etapa externa.
- **Receipt:** evidência verificável do envio oficial.
- **Manual Action:** impedimento conhecido que exige intervenção e não equivale a falha genérica.
