# Submission — linguagem do domínio

- **Official Form:** formulário público da InHire na Canonical Job URL.
- **Field Mapping:** tradução determinística de dados internos para um controle do Official Form.
- **Browser Session:** contexto Playwright isolado de uma Attempt.
- **Submission Receipt:** evidência da resposta oficial e confirmação visual de sucesso.
- **Unsupported Form:** formulário ativo cuja semântica não pode ser preenchida com segurança.
- **Submission Outcome:** `SUCCEEDED`, `RETRYABLE_FAILURE`, `PERMANENT_FAILURE` ou `MANUAL_ACTION_REQUIRED`.
