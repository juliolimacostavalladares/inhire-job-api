# Candidate — linguagem do domínio

- **Candidate:** User que procura vagas.
- **Candidate Profile:** representação revisável da trajetória, contato, localização e preferências.
- **Profile Import:** tentativa de extrair um Profile de um documento.
- **Profile Readiness:** avaliação objetiva de campos necessários para uma ação.
- **Application Data Snapshot:** dados mínimos e imutáveis preparados para uma candidatura específica.
- **Auto-Apply Policy:** consentimento e limites do Candidate para candidaturas automáticas.
- **Needs Review:** estado em que dados importados existem, mas exigem confirmação do Candidate.
