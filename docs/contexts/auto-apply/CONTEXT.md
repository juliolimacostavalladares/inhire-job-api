# Auto Apply — linguagem do domínio

- **Eligibility:** condição booleana que permite avaliar uma vaga.
- **Policy:** consentimento, score mínimo, limite diário e preferências do Candidate.
- **Candidate-Job Match:** avaliação versionada entre Candidate Profile e Job Snapshot.
- **Daily Quota:** máximo de novas intenções automáticas no fuso do Candidate.
- **Auto-Application Decision:** decisão auditável de criar ou rejeitar uma Application Intent.
